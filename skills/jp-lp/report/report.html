1. 要旨

この調査で最も重要な発見 日本のLPは、統計的に別物の2つの母集団に分かれる。「日本のLPといえば縦長・赤字・吹き出し・マンガ」という通説は、デザインギャラリーに載るLPでは棄却され、広告配信専用のLPでは支持された。通説そのものが誤りだったのではなく、通説が指していた層がギャラリーに載らない層だった。どちらを作るのかを最初に決めないと、設計言語が混ざったLPができる。

1.1 検証された通説

  • 日本のLPは長い。 縦の長さを判定できた47件中38件（80.9%）が「非常に長い」（モバイル10,000px超）。広告配信型でも55件中41件（74.5%）。
  • CTAは繰り返し置く。 計測できた46件でページ内CTA回数の中央値は7回、5回以上が76.1%。1回だけなのは1件（2.2%）のみ。
  • FVの情報密度は欧米より高い。 目視カウントで日本19件の中央値12ユニットに対し、欧米6件は5ユニット。ただし標本が非対称なため、方向としては裏付けあり、倍率は断定不可。

1.2 覆された通説

  • 「日本のLP＝マンガ」は両母集団で棄却された。 広告配信型でも2/54（3.7%）、しかも2件とも投資・不動産投資。健康食品16件・化粧品14件・医療脱毛8件では0件。LP archive 46,006件のスタイルタグでも「マンガ・イラスト」は3.8%にとどまり、最大タグは「シンプル」28.9%。
  • 「日本のLPは装飾過多」は、CV目的LPの実測では逆。 袋文字 0/42、和文italic 1/42、蛍光マーカー 4/42。生き残っている強調手段は赤字＋太字だけ（16/42、38%）。
  • 「モバイルLPは固定追従CTAが必須」は測定法で5%から87%まで割れる。 単一の全国値は出せない。記事LPでは17件中0件、医療系では7件中6件。

1.3 実務上、最も重い含意

多くの日本のLP案件は、統計的に有意なA/Bテストが成立しない CVR 1% で 20% の改善を検出するには片群約4.3万セッションが必要。月間CV 30件以下の案件ではテストが成立しない。「テストで決める」という前提自体が使えない現場が多数派になる。そして日本市場には、比較の基準にできる業種別CVRベンチマークが出典付きで1件しか存在しない（しかも内部矛盾がある）。

2.3 手法上の限界（結論の読み方を変えるもの）

HTMLのテキスト検索では日本のLPは測れない 日本のLPは価格・CTA・打消し表示を画像に焼き込む慣行が強い。実測30件中13件（43%）がFV内に生テキストを2ブロック以下しか持たなかった（欧米16件では0件）。テキスト検索での「記載なし」は「存在しない」を意味しない。本調査でもWebFetchベースのレーンは装飾の出現率が下振れしている可能性がある。
  • CVRのデータは一切ない。 測ったのは出現率だけ。出現率の高さは「その業界で慣行として定着している」ことしか意味しない。「装飾が濃い＝効く」と読んではいけない。
  • 広告配信型の標本はMeta広告ライブラリ由来。 Google透明性センター、Yahoo!、LINE、TikTok の遷移先は未確認。出稿量の多い広告主に寄っている。
  • 日本と欧米のFV比較は統制されていない。 日本＝広告専用LP、欧米＝トップページという非対称、地域配信の汚染、Cookieバナーの遮蔽がある。

2.4 ツール制約（起きたことをそのまま書く）

当初 Perplexity API を主要な情報源として使う計画だったが、全レーンで HTTP 401（insufficient_quota）を返し、一度も使用できなかった。代替として WebFetch、HTTP直接取得、e-Gov 法令API、ヘッドレスブラウザ、pdftotext を使用した。法規制と媒体ポリシーの領域では、要約サービスより一次資料の直接取得のほうが証拠として強いため、実質的な品質低下は生じていない。WebSearch もセッション上限（200回）に到達し、後半のレーンでは使用できなかった。

3.1 なぜ割れるのか

ギャラリーは「作品として見せられるLP」を選ぶ。その選抜フィルタが赤字・吹き出し・比較表を落とす。一方で広告配信型は露出のたびに課金されるため、可読性より読み進め率と刺さり方が優先され、装飾が濃くなる。

業種ではなく「誰が作ったか」で割れる 化粧品は二層に分かれる。大手ブランドの公式LP（アスタリフト、アテニア、ディセンシア、ライスパワー、オルビス本体）は赤字も吹き出しも比較表もゼロ。同じ化粧品でも記事LP・単品通販カート型（CAC、KATAN、インナーシグナル、アースケア）は装飾が濃い。ブランド本体が作るのか、DR事業部・代理店が作るのかで設計言語が別物になる。

4. 発見2：記事LPという第3の型

広告配信型55件中17件が /ab/ パスを持つ記事LP（アドバトリアル）。Squad beyond 等のツールで作られる。装飾の濃さが別格で、他のどの型とも別に扱う必要がある。

指標記事LP（n=17）記事LP以外
赤字・黄色マーカー17/17（100%）大きく下回る
吹き出し12/16（75%）同上
縦の長さ中央値29,078px14,821px（ちょうど2倍）
固定追従CTA0/17（0%）あり

ドメインが sb-〇〇.discover-news.tokyo、sb-〇〇.service-info.jp のように広告主ドメインとは別のニュースメディア風サブドメインになっているのが特徴。冒頭または末尾に小さく「PR：株式会社〇〇」と表示される（ステマ規制対応と思われる）。

4.1 記事LPの構造

体験談風の書き出し（一人称・悩みの提示）
 → 原因の解説（図解・赤字強調・黄色マーカー）
 → 商品の登場（「あの大正製薬が」＝親会社の権威借用）
 → 臨床試験グラフ・機能性表示食品の届出訴求
 → お客様の声
 → 価格開示（通常価格に取り消し線＋初回価格）
 → 4問前後のアンケート（クリックのみ）
 → 「ご回答ありがとうございました！」→ 特別価格ページへ送客

末尾アンケートは、同意の階段（コミットメントと一貫性）を作りつつ、フォーム到達前に離脱者を切って広告計測上の到達品質を上げるためと考えられる（推定）。55件中、ラジオ・チェックボックスを3個以上持つLPは20件あった。

4.2 もう一方の極：1画面完結型

3,000px未満の「1画面完結アンケート型」が広告配信型55件中7件（12.7%）。開いた瞬間に「Q1 今までに脱毛をした経験はありますか？」のような設問が出る。転職系では「LINEで担当者が紹介します」型に変わる。

含意 日本の広告配信LPは「極端に長い」と「極端に短い」の二極化が起きている。「日本のLP＝縦長」を単純に適用すると外す領域がある。

5. 発見3：FVコピーの画像焼き込み

実機計測30件のうち13件（43%）が、FV内に生テキストを2ブロック以下しか持たず、代わりに大きな画像を配置していた。対照した海外16件では0件。

5.1 何が壊れるか

  • SEOが効かない（何のページか機械可読でない）
  • アクセシビリティが壊れる（スクリーンリーダー、文字サイズ変更、コントラスト設定）
  • A/Bテストのテキスト差し替えができない（改善サイクルそのものが止まる）
  • 翻訳・多言語展開ができない
  • 監査でHTMLテキスト検索をすると「記載なし」と誤判定される
法的リスクとしての側面 価格・打消し表示まで画像に焼き込むと、景品表示法上の打消し表示として機能しない可能性がある。消費者庁は打消し表示について「同一画面にある他の表示と比べても、打消し表示がより注意を引き付ける文字の大きさにすること」を求めている。画像内の小さな文字はこの要件を満たさない。

やるなら意図してやること。惰性でやらないこと。 焼き込むと決めたなら、最低限 alt に本文を入れ、打消し表示だけは必ずHTMLテキストで別途置く。

6. 業種別の実態

6.1 単品通販・D2C（化粧品／健康食品）

標準形は縦長1カラム＋ページ末尾フォーム一体型。カート遷移を挟まない。ブロック順序は「共感 → 原因 → 商品 → 権威 → お客様の声 → 理由の数え上げ → 開発ストーリー → オファー → 保証 → Q&A → 最終CTA → 追伸」。

「追伸」ブロックの存在は日本の通販LP特有で、ダイレクトレスポンス広告のレターフォーマットが残存している証拠。

2022年6月改正特商法で規制の主戦場が移った 規制の焦点はLP本文ではなく「最終確認画面」に移った。LP末尾フォーム型の場合、そのフォーム画面自体が最終確認画面に該当しうるため、定期条件の記載位置がそのまま法令リスクになる。「特商法表記ページに書いたから最終確認画面では省略」は通らないとガイドラインが明言している。

また「定期縛りなし」「回数縛りなし」という表記は安全弁にならない。国民生活センターは2025年1月31日に注意喚起を公表し、回数縛りがないことと1回限りの購入であることを区別して表示すべきと指摘している。行政処分は誇大広告と最終確認画面違反のセット適用が定型化している。

6.2 BtoB SaaS・士業

日本のBtoB SaaSの第一CTAは「無料トライアル」ではない 実測8製品中7つが「資料ダウンロード」を第一CTAに置いていた（SmartHR、クラウドサイン、MiiTel、b→dash、SATORI、bellFace、楽楽精算）。対して欧米発のHubSpot日本語版は「デモを申し込む」「無料で試してみる」の2択で、資料DLを第一CTAに置いていない。料金すら「料金表をもらう」というリード化オファーに変換するのが日本型の定石。

フォーム項目数の実測は、資料DL 7から8項目、デモ・トライアル 11から12項目、問い合わせ 8から14項目。国内の二次情報が示す「トライアル3から5項目」よりも一貫して多い。SmartHRの問い合わせは14項目全必須。

見せる項目を絞る代わりに非表示フィールドで企業データを補完するのが標準実装。SmartHRのMarketoフォームには非表示27項目（utm 5種＋gclid＋法人番号・資本金・売上等の企業属性14項目）が仕込まれている。

士業は規制が別物。最も見落とされやすいのは日弁連の業務広告規程で、診断フォームで電話番号を取得しても「この送信をもって法律相談の申込みとする」旨がページ上で明確でない限り、架電もメールもSMSもLINEも規程違反になる。

6.3 医療・クリニック（自由診療）

42ドメインを実測して、限定解除の4要件を完全に満たすLPは1件も確認できなかった 最頻の欠落は「治療期間及び回数」。費用だけ書いて期間・回数を落とす型が支配的だった。

この領域の構造上の核心は二段構えにある。リスティング広告・バナー広告は限定解除要件①（患者等が自ら求めて入手する情報）を満たさないが、そこからリンクされたLPは満たす。つまり広告クリエイティブと遷移先LPで、法的に書ける内容が異なる。これがこの領域のLP設計そのものを規定している。

費用・リスクをリンク先へ逃がす構成はガイドラインと事例解説書が明文で禁じている。適合度が高かったのは品川美容外科（副作用・リスクを料金の直近に配置）と銀座総合美容クリニック（症例写真の直下に費用とリスクを1つの注記で併記）。

体験談は限定解除でも解除されない省令の禁止事項で、口コミ転載・スタッフ自身の体験談・患者アンケートの加工まで対象になる。実測でも歯科自費サイトは揃って「お客様の声」を置かず症例写真＋注記で代替していた。医療法適用外の整体・接骨院だけが体験談と不安訴求型FVを維持している。

取り締まりは景品表示法側が先行している。ステマ告示による医療機関への措置命令が2件（医療法人社団祐真会 2024年6月、医療法人社団スマイルスクエア 2025年3月）。ネットパトロール通報は令和5年度4,854件から令和6年度7,052件に増加した。

6.4 教育・人材・スクール

「無料」は必ず「所要時間」とセットで書くのが実測上の標準形。「簡単30秒で無料登録」「3分で登録完了」「30秒でカンタン予約」「かんたん1分 無料体験レッスンのご予約」「【最短1分】無料登録スタート」。無料であること単体ではなく、投下する時間コストの小ささを並記する。

そして「断ってよい」と明示するコピーが高関与オファーの緩衝材として機能している。「体験授業で入塾を決めなくていい」（東京個別指導学院）、「一人でできそうなら入塾しなくてかまいません」（武田塾）、「ビデオオフでもOK！」（ポテパンキャンプ）。

法規制の分岐として、語学教室・家庭教師・学習塾・パソコン教室は期間2か月超かつ5万円超で特定継続的役務提供に該当する。一方プログラミングスクールは原則非該当（経産省のグレーゾーン解消制度の回答）。これがテックキャンプの特商法表記に法定記載がなく、語学系のトライズ・プログリットが法定上限と一致する解約金を記載している理由を説明する。

「期間限定」の常態化には措置命令の実例がある 株式会社キャリアカレッジジャパンは、平成22年5月から平成26年7月までほぼ常時1万円割引を実施しながら「期間限定」と表示したとして、2015年3月20日に措置命令を受けている。実測でも、日付を当日にして毎日書き換えている実装（2026年8月5日に「8月5日（水）限定」表示）が観測された。この型は直撃する。

6.5 高額・長期検討型（住宅／不動産／保険／金融）

実物確認した注文住宅16サイトのうち、即決CTAを置いていたサイトはゼロ件。 主流は「カタログ請求」「来場予約」「オンライン相談」の3本立て。

ただしフォーム項目数の実態は大きく割れる。同じ「資料請求」でも住友不動産が全14項目（必須9、3ステップ分割）に対し、桧家住宅は全49項目（必須12）で、任意項目に年収・総予算・住宅ローン・融資事前審査希望まで含む。しかもFVには「1分で完了」と表示されている。CTAの文言とフォームの実態を乖離させてはいけない。

「営業されるのが怖い」の打ち消しは、一括見積もり型では事実上の必須ブロック。しかも運営が営業を止める仕組みまで明示するのが日本的（ヌリカエの「お断り代行」、ソーラーパートナーズの「イエローカード制度」）。

金融LPの設計上の制約 金商業等府令第73条第2項により、リスク情報は「当該事項以外の事項の文字又は数字のうち最も大きなものと著しく異ならない大きさ」で表示しなければならない。つまりFVのキャッチコピーを大きくするほど、リスク表示も連動して大きくせざるを得ない。デザイン上の自由度が法令で縛られる数少ない例。

不動産では表示規約第18条により「完全」「絶対」「日本一」「格安」「厳選」が根拠資料なしには使えず、徒歩は道路距離80m＝1分・端数切り上げ、「新築」は完成後1年未満かつ未入居。おとり広告ガイドラインは物件情報の更新間隔を最長2週間と明記しており、物件掲載型LPを作って放置するのは規約違反に直結する。

7.3 日本語の「大きな文字」は18ptではなく22pt

WCAG 2.1 達成基準1.4.3の解説は、日本語の全角文字について「22ポイント又は18ポイントの太字」を同等サイズとみなすのが妥当とし、「22ptと18ptは約29pxと24pxに相当する」と明記している。

実測の見出し font-size 中央値は19.1px。 つまり日本語LPの見出しの大半は3:1の緩和（大きな文字）の対象外で、4.5:1が必要になる。英語圏の「18pt以上なら3:1でよい」をそのまま適用すると基準を外す。

7.4 打消し表示の文字サイズ（最大の実務ギャップ）

消費者庁は「打消し表示がより注意を引き付ける文字の大きさにすること」を求めている。にもかかわらず実測では14px未満のテキストを持つLPが37/42（88%）、最大で1ページ478要素。

さらに消費者庁の調査（回答1,000名）では、拾い読み66.5%、非スクロール40.4%、注釈見落とし68から94%。注記を小さくするのはデザインの問題ではなく法的リスクである。

7.6 モバイル・フォーム・決済

固定追従CTAを実装するなら、実測値は高さ中央値83px、幅100%（10/11件）、文言は動詞＋（無料 or 所要時間）。表示タイミングはFVから常時7件対スクロール後出現5件に割れるが、FVには本体CTAがあるため追従バーはFVを塞ぐだけになりやすく、デフォルトはスクロール後出現が妥当。

実在する事故として、プレミアムウォーターは下部88pxの追従CTAとは別にCookie同意バー（高さ248px、z-index 99999）が下部を占有し、35%地点・75%地点の両方で追従CTAが覆われていた。

フォームでは郵便番号住所自動入力・ふりがな自動入力・全角半角自動変換の3点が差別化ではなく前提条件（国内EFOツールが揃って標準搭載）。効くのは必須・任意の切り替えではなく項目そのものの削除で、WACUL調査では1項目減で通過率が約2ポイント向上、必須にしても任意にしても通過率は変わらないと報告されている。

決済はクレジットカード67.3%、PayPay 30.4%、Amazon Pay 14.9%。よく利用する決済手段がない場合、56.5%以上がそのサイトを離脱する。カゴ落ち率は63.48%（2026年上半期、2,250サイト）。LP一体型カートはこの遷移離脱を構造的に潰す設計。

日本語WebフォントはLCPを壊す最大の単一要因 Noto Sans JP フルセットは1ウェイトで1.5から2MB規模。英字フォントと桁が違う。国内事例で3ウェイト6.05MBを整理して Speed Index 3.3秒から1.7秒、別事例でLCP 2.8秒から0.2秒という改善が報告されている。LPは文言が固定されるためサブセット化の効果が最大化する。

7.7 素材写真＋吹き出しは規約違反になりうる

PIXTAの規約は「人物素材に吹き出しを付けて商品利用の印象を与える使用」を明確に禁止している。日本のLPの定番構成である「素材写真＋吹き出しのお客様の声」は、この規約に抵触する。医療LPではそもそも体験談自体が禁止されている。

8. 法規制はクリエイティブの上流にある

日本のLPで最も欧米と違うのは、規制がコピーの前段に来るという点である。後から直すと全部書き直しになる。法令原文は e-Gov 法令検索の公開APIから条文XMLを取得して照合した。

8.1 コピーを書く前に確定する4点

  1. 商材の法域：化粧品／医薬部外品／健康食品／機能性表示食品／医療／金融／不動産／人材。ここで書ける言葉の上限が決まる。
  2. 定期購入か単発か：定期なら特商法12条の6が独立の義務として乗る。
  3. 第三者の声を使うか：使うならステマ告示の明瞭表示が要る。自社LPも例外ではない。
  4. 数値・No.1を出すか：出すなら15日以内に根拠資料を提出できる体制が要る。

8.2 最も誤解されている5点

1. 打消し表示でリスクは消せない 消費者庁は「体験談＋『個人の感想です』」型について、打消し表示が明瞭に記載されていても一般消費者の認識は変わらないと明言している。体験談を使うなら、被験者数・属性・同じ効果が得られた者の割合・得られなかった者の割合を明瞭に表示する必要がある。
2. 日本型LPの標準構成そのものが景表法上の論点 消費者庁は、アコーディオンパネルに打消し表示を入れること、CVボタンと打消し表示が別画面になっていること、「※」だけで別画面へ誘導することを名指しで問題視している。縦長1カラム＋固定追従CTA＋アコーディオン注記＋フッター極小注記という日本型LPの標準構成は、構造レベルでリスクを抱えている。小手先ではなく構造の是正が要る。
3. No.1表示は「調査があること」では足りない 4要件（比較対象の適切な選定／調査対象者の適切な選定／公平な調査方法／表示内容と調査結果の適切な対応）をすべて満たす必要がある。検索上位N社だけの比較、自社顧客・自社社員のみの調査、利用経験を聴取しないイメージ調査はいずれも明示的に否定されている。「〜したい」「〜と思う」を付けても逃げ切れない。フッターの極小文字に選定条件を書く運用は報告書が直接否定している。第三者調査会社に外注しても責任は広告主にある。
4. 外部送信規律は通常の自社商材LPにはかからない 電気通信事業法の外部送信規律について「LPに広告タグを入れたら全部対象」というのは誤り。総務省の判定は、(1) 自己の情報発信のための企業ホームページか、(2) 自社の本来業務としての商品オンライン販売か、なら対象外。対象になるのは広告・アフィリエイト収益で運営するメディア型・比較サイト型。ただし「LPだから常に対象外」も誤りで、判定はサービスの性質で行う。

またConsent Mode v2 は日本では必須ではない（Googleの該当ヘルプはEEA向けと明記）。欧州向けのCookieバナーを流用しても日本の要件は満たせないし、日本で必要とも限らない。両者は別制度。
5. 2024年10月1日以降、景表法違反は刑事罰のリスク領域 改正景表法で優良誤認・有利誤認に直罰（100万円以下の罰金、両罰規定あり）が入った。加えて10年以内の再違反で課徴金1.5倍（3%から4.5%）、売上額の推計規定、確約手続が新設された。確約手続は「繰り返し違反、悪質重大な違反被疑行為の場合は対象外」であり、制度の存在を「後で直せばよい」の根拠にしてはいけない。措置命令は公表されるため、行政処分そのものより公表と報道による事業インパクトのほうが大きい場合が多い。

8.3 二重価格の数値基準

比較対照価格として過去の販売価格を使うには、次をすべて満たす必要がある。

  • セール開始時点からさかのぼる8週間（販売期間が8週間未満ならその期間）で、
  • その価格での販売期間が販売期間全体の過半を占め、かつ
  • その価格での販売期間が通算2週間以上あり、かつ
  • その価格で最後に販売した日から2週間以上経過していないこと。

9. 媒体別のLP要件

審査対象は広告文だけではない。Googleは「広告およびリンク先」への適用を明記し、LINE広告は審査対象にランディングページとリンク先URLを含む。LPを直すまで広告は回らない。

Metaの「個人的属性」ルールが日本語LPの定番構文を直撃する Metaは広告が個人的属性を主張・示唆することを禁じている。日本語で多用される「あなたも◯◯でお悩みではありませんか？」「◯◯世代のあなたへ」「他の◯◯の方も使っています」はこの構文にそのまま該当する。属性を主語にせず、商品・サービスの便益を主語にする必要がある。

広告配信型LPのFV最頻型が「不安・悩み訴求」（45.5%）であることを踏まえると、訴求の型そのものを媒体に合わせて書き分ける必要がある。

一方でMetaのビフォーアフター全面禁止は誤り。2026年7月22日更新のポリシーは許可側に「一般的な化粧品・施術・手術のビフォーアフター」を明記しており、禁止されているのは外見の劣等性の断定と脂肪をつまむクローズアップ。ただし媒体ポリシー上は可でも、日本では薬機法・医療広告ガイドライン側で別途規制されるため二重に確認が要る。

日本固有の分岐が3つ確認できた。

  • Googleの金融サービス「適格性確認」に日本は入っていない。 29の対象国リストに日本は未収載。日本の金融系LPで効くのは媒体の認証ではなく金商法・貸金業法側の規制。
  • TikTokは日本を言語・通貨の厳格執行市場に指定。 日本語必須で、第三者サイトへ誘導するQRコードも禁止される。
  • LINE広告は「在庫わずか」等の急かし表現を明示的に否認。 日本のLPで多用される限定・緊急性演出は通らない可能性が高い。

実測したLPのURLには _facebook、_fb、meta、asc といった配信面識別子が入っており、同じ商材でも媒体ごとに別LPを用意していることが読み取れる。1本のLPを全媒体に流すのは実勢から外れている。

この章の空白 Yahoo!広告のポリシーは未確認。 本調査では ads-help.yahoo.co.jp がDNS解決不可、代替ドメインがSPAで本文を取得できなかった。日本市場では無視できない媒体であり、健康食品・美容・医療の審査基準や必要書類の提出要件が独自にある。到達可能な環境からの再取得が最優先の積み残しである。

10. 計測とABテストの現実

10.1 使えるベンチマークが存在しない

日本市場の業種別CVRベンチマークとして国内・出典付きで見つかったのは、Ptengine「13業界別Webサイトのベンチマーク指標」1件のみ。母数は「各業界30程度・大手中心」と明記されている一方、調査期間・セッション基準かユーザー基準か・マイクロCVを含むかは未記載である。

しかもこの1件にも実地検証で内部矛盾が見つかった。「上位25%」の意味が同社の別記事と反転している、美容健康のFV離脱率に同値の誤記がある、中央値と平均値が極端に乖離する業種がある（医療 0.72% 対 5.21%）。それ以外の日本語CVR解説記事は、出典が海外（Unbounce等）か出典記載そのものがなかった。

流入チャネル別のLP CVRは、日本市場で出典の揃った公開データが存在しなかった。本調査では数値を提示しない判断をした。

10.2 そのLPでABテストは成立するか

CVR 1% で 20% の改善を検出するには片群約4.3万セッションが必要。才流は「BtoBサイトの月間セッション数は通常数千から数万」「月5,000セッションでCVRを0.1ポイント上げてもCV数は5件しか増えない」として、CVR 1% 以上を達成したらサイト改善を止めて集客強化に振ることを勧めている。

成立しない場合の代替は、多変量テスト（セル数が増えるぶん必要サンプルが跳ね上がるため最悪の選択）ではなく、逐次的な大胆変更＋マイクロCV＋定性調査である。

10.3 成立する場合のルール

  • 期間は最低2週間（曜日効果の平準化）。上限6週間（外部要因の汚染）。
  • ピーキング禁止。 毎日p値を確認して有意になった時点で終了する運用では、偽陽性率が名目上の5%から最大26%に跳ね上がる。Adobe Target も早期終了を「10個の重要な落とし穴の1つ」と明記している。
  • 「◯◯%改善」の定義を固定する。 相対改善率か絶対ポイント差か。実際に、ある国内記事はタイトルで「CVRを2.19%改善」と書きながら本文の実数は「2.84%から5.03%」であり、同じ記事内で2つの意味が混在していた。

10.4 国内事例の使い方

国内ABテスト事例の改善率は、ほぼ全てが検証不能 50件収集して、期間と母数の両方が明記されていたのは1件のみ。約48件が「条件不明」だった。提案資料に事例を引く際は「条件不明」と併記しない限り使ってはいけない。

なお「オファーの変更が最も効く」という業界の定説について、本調査では裏取りに失敗した。収集した50件の観察としては、相対100%超の改善はほぼ全てが訴求軸・ターゲット・オファーの変更であり、色や配置の微修正は1桁から十数%にとどまったが、これを定量比較した国内調査は見つからなかった。提案で断定してはいけない。

Google Optimize は2023年9月30日に終了した。Googleが公式に名指しした後継はAB Tasty／Optimizely／VWOの3社だが、日本語サポートを公式サイトで確認できたのはAB Tastyのみ。実務の主流は国産（KARTE Blocks 月14.8万円から、DLPO 月10万円から、SiTest、Ptengine、Kaizen Platform）である。

PASONAの法則は一次情報で確認できなかった 神田昌典公式サイトの書籍ページを実際に開いたところ、サブタイトルが「新・PASBECONAの法則」と表記されていた。一方、書誌検索結果および複数の二次記事は同書を「新・PASONAの法則」と表記している。どちらが正か本調査では確定できなかった。各要素の定義原文も一次情報からは取得できていない。AIDMA／AIDA／QUEST／BEAF も同様に出典未確認。提案資料で「PASONAの法則に基づき」と書かないこと。

このほか、総額表示義務の特例終了日（2021年4月1日）の一次確認（財務省URLが404、国税庁ページがShift-JIS配信の空スタブ）、「漢字率3割が読みやすい」説の学術的裏付け、一部キャッチコピー型の実物LP引用が未達である。

11.3 媒体・計測

Yahoo!広告のポリシー全般（最優先）、Google透明性センター経由の遷移先LP、アフィリエイトASPの案件LPが未着手。line-height の和文推奨倍率については、W3C JLReq に推奨倍率の明示がないことを確認済みで、実務値の根拠は実測と二次情報のみである。
