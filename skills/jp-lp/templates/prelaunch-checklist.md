# LP公開前チェックリスト

**モバイル実機（幅390px、JS実行後）で確認すること。** HTMLのテキスト検索だけで判定しない。

条文の詳細と公式URLは [`../references/legal.md`](../references/legal.md)。

---

## 1. 表示と根拠（全業種）

- [ ] LP上のすべての効果効能・数値主張について、**15日以内に提出できる根拠資料**を台帳で
      紐づけてある
- [ ] 打消し表示・注釈が**他の文字より小さくなっていない**
- [ ] 打消し表示が**アコーディオンの中に隠れていない**
- [ ] **CTAボタンと打消し表示が同一画面**にある（別画面に分かれていない）
- [ ] 「※」記号だけで別画面へ誘導していない
- [ ] 成分の試験結果を商品の効果として書いていない

## 2. 体験談・お客様の声

- [ ] 体験談を使うなら、被験者数・属性・**効果が得られなかった者の割合**を明瞭に表示している
- [ ] 「個人の感想です」だけで済ませていない
- [ ] 併用条件（食事・運動）や適用条件（BMI等）を明示している
- [ ] 依頼して書かせたコメント・監修者の声に、依頼の事実を明瞭に表示している
- [ ] インフルエンサー投稿を転載しているなら、**転載先でもPR表記がある**
- [ ] （医療）体験談を**一切載せていない**

## 3. No.1・順位・満足度

- [ ] 比較対象に市場の主要な同種商品を含めている（検索上位N社だけにしていない）
- [ ] 調査対象者が自社顧客のみ・自社社員になっていない
- [ ] 「顧客満足度」なら利用経験の有無を確認している
- [ ] 1位が出るまで調査を繰り返していない
- [ ] イメージ調査を根拠にしていない
- [ ] 注記が**一般消費者にとって明瞭な位置・大きさ・色**である（フッター極小文字ではない）
- [ ] 「〜したい」「〜と思う」で逃げていない

## 4. 価格

- [ ] **税込を明瞭に表示**している
- [ ] 二重価格の比較対照価格が4基準を満たす（8週間・過半・通算2週間・最後の販売日から2週間）
- [ ] 「〇日以降は通常価格〇〇円」と書いたなら、実際にその価格で販売する
- [ ] 「期間限定」「カウントダウン」を出したなら、**締切後に本当に価格を戻す運用**になっている
- [ ] 景品・特典が上限を超えていない（不動産は上乗せ規制あり）

## 5. 定期購入・継続課金

- [ ] 最終確認画面（LP完結型ならフォーム画面）に**6項目**を表示している
- [ ] 「特商法表記ページに書いたから省略」になっていない
- [ ] CTAごとに定期条件を再掲している
- [ ] 「定期縛りなし」と書くなら、1回限りの購入との違いを区別して表示している

## 6. 商材別

### 化粧品・医薬部外品
- [ ] 効能効果が**56項目の範囲内**
- [ ] 体験談を使っていない（使用感の説明のみ例外）
- [ ] **ビフォーアフター写真を使っていない**（期間併記はさらに不可）
- [ ] 「医師推薦」「学会推奨」を書いていない
- [ ] 「すぐれたききめ」「よくききます」を使っていない
- [ ] 一般向けに臨床データ・実験例を例示していない

### 健康食品・機能性表示食品
- [ ] 疾病の治療・予防、身体機能の一般的増強を標榜していない
- [ ] **届出成分以外の成分を強調していない**
- [ ] 「消費者庁認可」「国が認めた」と書いていない
- [ ] 届出表示を意訳・省略・強調変形していない
- [ ] 健康被害の連絡窓口を案内している
- [ ] 商品ではなく成分の効果を強調する表示になっていない

### 医療（自由診療）
- [ ] 限定解除の4要件をすべて満たしている
  - [ ] 患者が自ら求めて入手する情報を表示するサイトである
  - [ ] **問い合わせ先を明示**している
  - [ ] 治療内容・標準的な費用・**治療期間・回数**を掲載している（回数の欠落が最頻）
  - [ ] 主なリスク・副作用を掲載している
- [ ] 費用・リスクを**リンク先に逃がしていない**
- [ ] 費用を「〇〇円から」の下限のみで表示していない
- [ ] ビフォーアフター写真は**症例1件ごとに**治療内容・費用・期間回数・リスクを併記している
- [ ] 「日本一」「No.1」「最高」「最先端」「最適」を使っていない（客観的事実でも不可）
- [ ] 「今なら〇円でキャンペーン」型の費用強調をしていない
- [ ] 口コミ依頼・症例モニターに対価を出していない（景表法側で処分実績あり）
- [ ] リスティング・バナー側は広告可能事項の範囲に収まっている

### 金融
- [ ] リスク情報が「**最も大きな文字と著しく異ならない大きさ**」である
- [ ] FVのキャッチを大きくした分、リスク表示も連動して大きくしてある
- [ ] 手数料・損失負担・違約金の表示が正確である

### 不動産
- [ ] おとり広告になっていない
- [ ] 「完全」「絶対」「日本一」「格安」「厳選」を根拠なしに使っていない
- [ ] 徒歩は道路距離80m＝1分・端数切り上げ
- [ ] 「新築」は完成後1年未満かつ未入居
- [ ] **情報公開日（直前の更新日）と次回の更新予定日**を表示している（更新間隔は最長2週間）

### 教育・スクール
- [ ] 特定継続的役務提供に該当するか判定した（7役務・5万円超・期間要件）
- [ ] 該当するなら概要書面・中途解約・クーリングオフの記載と整合している
- [ ] 合格率・就職率・年収アップの**分母と条件**を明示している

### 士業（弁護士等）
- [ ] 勝訴率・顧問先実績を書いていない
- [ ] 「最も」「一番」「顧客満足度」「完璧」を使っていない
- [ ] **診断フォームで連絡先を取るなら「この送信をもって法律相談の申込みとする」旨を
      ページ上に明示している**（無いと架電もメールもSMSもLINEも規程違反）

### 採用・求人
- [ ] 募集終了・条件変更後にLPを放置していない
- [ ] 令和6年4月からの追加明示事項に対応している
- [ ] 取扱求人件数・満足度に根拠がある

## 7. 個人情報・トラッキング

- [ ] **フォーム送信前に利用目的を明示**している（フッターのリンクだけではない）
- [ ] リードを提携先・代理店に渡すなら同意を得ている
- [ ] 広告タグの提供先が個人データとして取得する想定があるか確認した
- [ ] 外部送信規律の**判定フローを通した**（自社商材LPなら原則対象外）
- [ ] 対象と判定したなら3事項を通知・公表し、同意のチェックボックスにデフォルトチェックがない

## 8. 媒体審査

- [ ] フッターに該当する必須リンクが揃っている
- [ ] （Meta）「あなたも◯◯でお悩みですか？」型の**個人的属性構文**を使っていない
- [ ] （Meta）外見の劣等性の断定、脂肪をつまむクローズアップがない
- [ ] （LINE）「在庫わずか」等の急かし表現を使っていない
- [ ] （TikTok）日本語である。第三者サイトへ誘導するQRコードがない
- [ ] （Google／TikTok）独自コンテンツが十分にある（中継ページ・薄い比較ページでない）

## 9. 実装品質

- [ ] 本文 line-height が 1.6 以上
- [ ] 見出しの line-height が本文より詰まっている
- [ ] **14px未満のテキストが打消し表示に使われていない**
- [ ] CTAのコントラスト比が 4.5:1 以上（オレンジ＋白は要注意）
- [ ] 見出しのコントラストが 4.5:1 以上（日本語は22pt未満なら緩和対象外）
- [ ] 和文 italic を使っていない
- [ ] 下部固定CTAが Cookie同意バー・チャットウィジェットと**z-index衝突していない**（実機確認）
- [ ] Webフォントがサブセット化されている（またはシステムフォント）
- [ ] LCP を実機で計測した

## 9-2. 広告配信への適合（Google / Meta）

詳細は [`../references/ad-delivery-fit.md`](../references/ad-delivery-fit.md)。

**Google**
- [ ] P-MAXを使うなら、**最終ページURLの拡張の扱いを決めた**（デフォルトはオン）。
      LPが1枚しかないならオフにする
- [ ] 拡張をオンで使うなら、**ドメイン内の全ページ**が薬機法・景表法の点検対象になると理解した
- [ ] 拡張をオンで使うなら、**LP上の画像が広告アセットとして使われる**前提で、
      画像の利用許諾と焼き込み文言を点検した
- [ ] 検索キャンペーンでもAI最大化設定を使うなら、同じ拡張が効くことを理解した
- [ ] **サンクスページにメール等がDOMに出るか、`dataLayer.push()` を実装した**
      （「送信完了しました」だけだと拡張コンバージョンが空振りする）
- [ ] フォームの各 `input` に `id` を付けた
- [ ] **姓と名を2フィールドに分けた**
- [ ] hidden に `gclid` / `gbraid` / `wbraid` を**3つ別々**に持たせた
- [ ] **`gbraid` を小文字化していない**（大文字小文字が区別される）
- [ ] `click_time` と `order_id` をCRMまで引き回す設計にした

**Meta**
- [ ] **LPのURLを1本に固定した**（URL切り替えは学習をリセットする。中身の変更はしない）
- [ ] Advantage+ を使うなら、**FVを属性ではなく「場面」で名乗らせた**
- [ ] **個人的属性ポリシーの書き換えを済ませた**（"other" 相当語と二人称疑問形を消し、
      属性の帰属先をサービス側へ移した）
- [ ] インスタントフォームではなく**LPフォーム**を既定にした
      （インスタントフォームはLPイベントもEMQも Google共用も得られない）
- [ ] Pixel と CAPI を併用し、`event_id` を**LPテンプレート側で採番**した
- [ ] ドメイン認証を済ませた
- [ ] **Meta Business Tools Terms が要求する通知とオプトアウト導線**をLPに置いた
      （外部送信規律の対象外でも契約上必要）

**2媒体併用**
- [ ] `月間予算 ÷ 許容CPA` が30以上あるか確認した。無いならLPを分けず中間CVを足した
- [ ] **サンクスページを1本に統合**した
- [ ] CVRの分子を**GA4/CRMの実CV**に固定した（媒体管理画面の合計は水増しになる）
- [ ] Google側FVは「答えから」、Meta側FVは「場面から」で書き分けた（分ける場合）

## 10. 計測

- [ ] CVの定義を固定した
- [ ] LINE友だち追加をCVにするなら二重計測（GTMのタップ計測＋LINE側の追加経路）を組んだ
- [ ] フォーム送信・電話タップ・LINE遷移がすべて計測されている
- [ ] 媒体別にLPを分けたなら、URLで識別できる

## 11. 公開後の運用

- [ ] 価格改定・在庫終了・キャンペーン終了・届出変更・募集終了のたびに再点検するフローがある
- [ ] 物件・求人の掲載型なら更新サイクル（不動産は最長2週間）が決まっている
- [ ] 「本日限定」等の日付を自動書き換えする実装になっていない
      （常時実施の「期間限定」表示は措置命令の実例がある）
