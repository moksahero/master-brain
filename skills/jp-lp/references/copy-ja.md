# 日本語コピーの型と表記規範

実測LP 35件から約230件のコピーを収集（CTAボタン内約120件、マイクロコピー約45件、
数値実績約40件、価格表記約25件）。加えて制作会社が実在LPを紐づけて公開している
キャッチコピー56件を二次で収集。

## フレームワークの出典（2026-08-06 確定）

初版は「PASONA と PASBECONA のどちらが正か確定できない」として保留したが、決着した。

### PASONA と PASBECONA は別物。年で分ける

- **2016年『稼ぐ言葉の法則』（ダイヤモンド社）は「新・PASONAの法則」が正。**
  国立国会図書館の書誌（納本現物由来）2件が
  `稼ぐ言葉の法則 : 「新・PASONAの法則」と売れる公式41` で一致し、ダイヤモンド社の
  発売日記事（2016-02-13、神田昌典名義）も本文・見出しとも「新・PASONAの法則」。
- **著者公式サイトの「新・PASBECONA」表記は、サイト全体の文字列一括置換の産物。**
  同ページが「17年前に開発したPASBECONAの法則」と書いており、17年前＝1999年に
  PASBECONAは存在しない。置換痕は著者会社サイトの別2ページでも実測された。
- **PASBECONA は実在するが2021年の別書籍。** ダイヤモンド社公式書誌が
  『コピーライティング技術大全』（2021年11月）で「書籍として初公開」と明記。
  9要素は Problem / Affinity / Solution / Benefit / Evidence / Contents / Offer /
  Narrow down / Action。

**提案資料での書き方**：2016年書籍を参照するなら「新・PASONA」、2021年書籍なら「PASBECONA」。
**「1999年にPASBECONAを提唱」は著者側サイトの記述であっても誤り。**

### AIDMA を「ホールが1920年代に提唱」と書くのは誤り

岸志津江（東京経大学会誌326号）が **Hall の原著5冊を直接検証し「AIDMAの5文字は
見当たらなかった」と結論**している。Hall が実際に用いた型は **AICCA（1915）**。

**AIDMAは日本で広まった通説であり、Hall に帰属させないこと。**

### その他

- **AIDA**：出典に到達。
- **BEAF**：初出書籍は**2010年5月**（NDL書誌）。初版が書いた2011年は誤り。
  日本のLP業界特有の用語。
- **QUEST**：一次資料ゼロ。**出典不明のまま。提案資料で権威づけに使わない。**
- 各法則の**定義原文**（書籍本文）には到達していない。要素の並びは二次情報どまり。

## キャッチコピーの型（実例ベース）

制作会社コンバージョンラボが自社制作LP 56件を8指標（気づき／機能的価値／効果・成果／
価格的価値／情緒的価値／問題解決／実績訴求／注意喚起）に分類しているものを土台に、
実測33件のFVコピーと突き合わせて再編した。

| 型 | 使いどころ | 実例（実測） |
|---|---|---|
| 数値実績型 | BtoB、比較検討商材 | 「経費精算システム累計導入社数No.1※1」（楽楽精算）／「登録社数80,000社以上」（SmartHR） |
| ターゲット限定呼びかけ型 | セグメント明確な商材 | 「子育て、お仕事に忙しい日本のママへ」（京のすっぴんさん） |
| 不安・悩み提示型（一人称） | 広告配信型、記事LP | 「あれ…？LDLコレステロールと中性脂肪の数値が高め…」（大正製薬）／「40代「オバさん」と言われた私の肌が！」 |
| 権威借用型 | 親会社・研究機関の信用を借りる | 「あの大正製薬の」「あのロキソニンSでおなじみの第一三共ヘルスケア」「あのヤクルトが開発した青汁」 |
| ベネフィット直球型 | ブランド本体、BtoB | 「バックオフィスから、まるごとスマートに。」（SmartHR）／「みんな、つくれる。」（kintone） |
| 期間・簡便性型 | 手軽さが差別化になる商材 | 「60秒の朝革命」（京のすっぴんさん） |
| 常識否定型 | 既存手段への不満が強い市場 | 「今までのMAは、重すぎました」（ferret MA） |

**権威借用型は日本の広告配信型で特に強い。** 「あの◯◯が」という構文で親会社・グループ企業の
知名度を借りる。ただし薬機法上、化粧品・医薬部外品では「医師推薦」「学会推奨」は
明文で禁止されている（適正広告基準 第4の10、薬機法66条2項）。**借りてよい権威と
借りてはいけない権威がある。**

## CTAボタンの文言

実測120件から。**「無料」「所要時間」「不要なもの」の3語で心理的コストを削る**のが型。
ボタン内は名詞句か動詞終止形、7から15文字。

| パターン | 実例 |
|---|---|
| 無料＋所要時間 | 「簡単30秒で無料登録」「3分で登録完了！転職サポートお申込み」「30秒でカンタン予約」「かんたん１分 無料体験レッスンのご予約」「【最短1分】無料登録スタート」 |
| 資料化 | 「資料ダウンロード（無料）」「3分でわかる資料ダウンロード」「メールで資料を受け取る」「料金表をもらう」 |
| 動詞＋無料 | 「無料診断を始める」「無料で相談する」「新規会員登録（無料）」 |
| 追従バー | 「30秒でカンタン予約 カウンセリングを予約する」（PROGRIT） |

追従バーの文言は**動詞＋（無料 or 所要時間）**の型が支配的。

## マイクロコピー

ボタン下の一言。**「やらなくてよいこと」を先に打ち消す型**が支配的。

- 「クレジットカード不要」
- 「個人情報不要！」
- 「無理な勧誘は一切ございません」
- 「無料期間中はいつでも解約可能です」
- 「いきなり複数の会社から連絡が入ることはありません。」（ヌリカエ）
- 「強引な営業を禁止しています。」（ソーラーパートナーズ）
- 「体験授業で入塾を決めなくていい」（東京個別指導学院）
- 「一人でできそうなら入塾しなくてかまいません」（武田塾）
- 「ビデオオフでもOK！」（ポテパンキャンプ）
- 「＼他のスクールとの比較検討相談も可能です。／」（DIVE INTO CODE）

**日本市場では「売り込まれる恐怖」を先に無効化するのが、オファーの強化より効く場面が多い**
（実測上、高関与オファーでは全社が何らかの形で置いている）。

## 表記規範（一次資料で裏取り済み）

### 敬体と常体

**見出しは常体・体言止め、本文とマイクロコピーは敬体。** 規範と実務が一致している数少ない領域。

JTF日本語標準スタイルガイド（翻訳用）第4.0版（2026年7月25日、日本翻訳連盟 翻訳品質委員会）は
「本文が敬体であっても、見出しには常体や体言止めを使います」「見出しの文末には、
句点（。）を付けません」と規定。

実測でも一致：kintone は FV「みんな、つくれる。」（常体）に対しCTA横
「チームで30日間、kintoneを無料でお使いいただけます。」（敬体）。SmartHR は
FV「みんなが使うから、組織が変わる」（常体）に対し
「15日間の無料トライアルで実際の機能をお試しいただけます」（敬体）。

### 数字

**半角算用数字。大きい単位は漢字（万・億）に切り替え、カンマとの併用はしない。**

JTFスタイルガイドは「算用数字は『半角』で表記します」「漢字（単位語）を使った位取りと
3桁区切りのカンマを両方使うのは冗長です。通常は、どちらかを採用していれば問題ありません」と
規定し、例として「2,310 人の社員」「3万8000 人以上」を挙げる。

**実測33件でカンマと漢字単位語を二重に使ったLPは1件もなかった。**

### 価格

**税込を明瞭に出す。総額表示義務は消費税法第63条。**

国税庁タックスアンサーNo.6902が挙げるOK例：
「11,000円」「11,000円（税込）」「11,000円（税抜価格10,000円）」「11,000円（うち消費税額等1,000円）」
「11,000円（税抜価格10,000円、消費税額等1,000円）」「11,000円（税抜価格10,000円、税率10％）」
「10,000円（税込価格11,000円）」

実測でも税込明記が徹底されており（エックスサーバー「※料金はすべて税込価格です」、
さくら「表示価格は全て税込みです」）、税抜を大きく出す場合も必ず税込を併記していた。

**2026-08-06 追記：一次確認できた。** 初版で到達できなかった国税庁タックスアンサー No.6902 と
財務省FAQの本文取得に成功し、**消費税転嫁対策特別措置法の特例が2021年3月31日で終了し、
2021年4月1日から総額表示が完全義務化**という記述を確認した。断定して引用してよい。

### 数値実績の注釈

**数値実績には必ず「母集団・期間・調査主体」を注釈で書く。書けない数値はLPに載せない。**

実測でNo.1表記を出していた9社は**全社が調査機関名・調査期間・対象条件を注記していた**。

注釈が確認できず脆弱だった実例：坪田塾「30 → 60」、ポテパンキャンプ「就職率98%」。
分母を明示していた良例：フォーサイトは合格率の分母を「返金保証の条件テスト通過かつ
受験番号提出者」に二重に絞って明記。リクルートエージェントは厚労省統計を出典にNo.1を主張。

人材・求人分野では2022年10月1日全面施行の改正職業安定法により、「事業の実績に関する情報」も
的確表示義務の対象になっている。「実際の取扱求人件数1000件を1万件程度と表示」
「根拠なく顧客満足度が高い旨を表示」は明示的な禁止例。

## 「〜しませんか？」の距離感

勧誘の距離を一段縮める型として実務で使われている。PLAN-Bの事例では、CTA下部に
「登録費、利用費はずっと無料です。まずはお試しで登録してみませんか？」を追加し、
ボタン内を「今すぐサガツクをチェック」から「サガツクのサイトを見てみる」に変更して
CVRが1.90%から3.09%に改善したと報告されている（二次）。

**ただし検証期間・母数が記事に明記されておらず、条件不明。単独の根拠にはできない。**

## 避けるべき表現

1. **翻訳調**：主語の多用、無生物主語、「〜することができます」の多用。
2. **抽象語の空回り**：「最適化」「ソリューション」「シームレス」。何が変わるのかが消える。
3. **二重敬語**：文化庁「敬語の指針」（平成19年）に定義と定着例がある。
4. **Metaの「個人的属性」に触れる構文**：「あなたも◯◯でお悩みではありませんか？」
   「◯◯世代のあなたへ」「他の◯◯の方も使っています」は Meta のポリシーに該当し得る。
   属性を主語にせず、商品・サービスの便益を主語にする。詳細は
   [`ad-platforms.md`](ad-platforms.md)。
5. **医療での最上級表現**：「日本一」「No.1」「最高」「最先端」「最適」「最良」「最上」は、
   **客観的事実であっても**医療広告ガイドラインで禁止。
6. **薬機法での断定・保証**：「すぐれたききめ」「よくききます」はキャッチフレーズとして不可
   （適正広告基準 解説(9)）。

## 「漢字率3割が読みやすい」は実験で否定されている

初版は「学術的裏付け未確認」として保留したが、**否定する実験がある**。

杉山・小田（2015、日本心理学会第79回大会）は、**読みやすさは漢字要因では説明されず**、
むしろ**漢字率を下げると「子ども向け」という印象が出る**ことを報告している。
可読性に効くのは漢字率ではなく**漢字の連続長**。

**実務判断**：「漢字率3割に抑える」という指針を使わない。代わりに
**漢字が長く連続する箇所を割る**（読点、ひらがなの接続語、改行）。
