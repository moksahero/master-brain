# ブロック構造の型（業種別）

すべて2026-08-05に実物を開いて上から順に書き出したもの。既存の型から始めて、
理由があるときだけ外す。

## 共通の骨格

判定できた46件でページ内CTA回数の中央値は**7回**、平均6.6回。5回以上が35件（76.1%）、
7回以上が24件（52.2%）。CTAが1回だけなのは1件（2.2%）。
**CTAはページ内に繰り返し置くのが日本の標準。** これは母集団を問わず共通する。

## 単品通販・D2C（化粧品／健康食品）

標準形は**縦長1カラム＋ページ末尾フォーム一体型**。カート遷移を挟まない。

```
1. ヘッダー
2. メインビジュアル＋キャッチコピー
3. 共感（悩みの提示）
4. 原因の解説
5. 商品の登場・特性
6. 権威（開発者、監修、共同開発、受賞、メディア掲載）
7. 社会的証明（お客様の声）
8. 選ばれる理由の数え上げ（「3つの理由」）
9. 開発ストーリー
10. オファー（通常価格に取り消し線＋初回価格）
11. 保証（返金保証、解約条件）
12. Q&A
13. 最終CTA
14. 追伸
15. フッター（特商法表記・プライバシーポリシー・運営者情報）
```

**「追伸」ブロック**は日本の通販LP特有で、ダイレクトレスポンス広告のレターフォーマットの
残存。実物で確認できる（京のすっぴんさん）。

実例（実測、2026-08-05）：
- プライマリー スキンケアトライアルセット `https://www.primaryinc.co.jp/landing/trial_at.php`
- 京のすっぴんさん `http://www.suppinsan.com/cream/hiyake.html`
- リ・ダーマラボ `http://re-dermalab.jp/lp.html`

### 定期購入を扱う場合の必須設計

- **CTAごとに定期条件を再掲する**（エルシーノ型）。2022年6月改正特商法で規制の主戦場は
  LP本文から「最終確認画面」に移った。LP末尾フォーム型では**そのフォーム画面自体が
  最終確認画面に該当しうる**ため、定期条件の記載位置がそのまま法令リスクになる。
- **「定期縛りなし」「回数縛りなし」は安全弁にならない。** 国民生活センターは2025年1月31日に
  「『定期縛りなし』が『解約するまで続く定期購入』だったなんて…！」を公表し、回数縛りが
  ないことと1回限りの購入であることを区別して表示すべきと指摘している。
  https://www.kokusen.go.jp/news/data/n-20250131_1.html

## BtoB SaaS・業務システム

実測12製品から帰納した標準順序：

```
1. ヘッダー（資料DL／問い合わせボタンを常設）
2. ファーストビュー：カテゴリ名＋一言価値＋CTA 2から3本
3. 実績バー（導入社数／シェアNo.1／継続率）※注記付き
4. 課題提起（3コマから6コマの「あるある」）
5. 中間CTA（FVと同じ2ボタンを再掲）
6. 機能／解決策
7. 導入効果（数値）
8. 導入企業ロゴ ＋ 導入事例（業種別に分岐）
9. 第三者評価バッジ（ITreview／BOXIL／ITトレンド／調査会社）
10. 料金（実額 or 「料金表をもらう」へのリード化）
11. サポート体制・導入までの流れ
12. FAQ
13. 最終CTA（資料／相談／トライアルの3択）
14. 出典注記（※1から※n）
15. フッター
```

### 欧米SaaSとの決定的な差

**日本のBtoB SaaSの第一CTAは「無料トライアル」ではなく「資料ダウンロード」。** 実測8製品中7つ。

| 製品 | FVの第一CTA |
|---|---|
| SmartHR | 資料ダウンロード |
| クラウドサイン | 資料ダウンロード（無料） |
| MiiTel | 資料ダウンロード |
| b→dash | 3分でわかる資料ダウンロード |
| SATORI | 「SATORI」製品資料 |
| bellFace | サービス資料をダウンロード |
| 楽楽精算 | メールで資料を受け取る |
| （比較）HubSpot日本語版 | デモを申し込む／無料で試してみる |

**料金も「料金表をもらう」というリード化オファーに変換するのが日本型の定石。**
楽楽精算のFV直下は「メールで資料を受け取る」＋「料金表をもらう」。カオナビは
「3分でわかるカオナビ」＋「目的・企業規模別にわかる詳しい料金を知りたい」。

ただし**価格開示は二極化**している。実額を出しているのはクラウドサイン（Light 月額11,000円／
Corporate 月額28,000円）、Zoho CRM（月額3,260円から）、ferret MA（初期3万円／月額8万円から）、
楽楽精算トップ（初期100,000円税抜／月額30,000円税抜から）。

**FV直下ロゴは標準ではない。** ferret One と b→dash はFV直後にロゴ群を置くが、
kintone は中盤まで出さない。「知名度の高い顧客がいるか」に依存する。

## 医療・クリニック（自由診療）

**この領域だけは構造が法律で決まる。** 詳細は [`legal.md`](legal.md) のD節。

核心は**二段構え**：

```
広告クリエイティブ（リスティング・バナー）
  └ 限定解除要件①を満たさない → 広告可能事項のみ
       ↓ 遷移
遷移先LP
  └ 「患者等が自ら求めて入手する情報」＝要件①を満たす → 限定解除可能
```

LP側の必須ブロック（限定解除の4要件）：

```
1. FV
2. 問い合わせ先の明示（要件②）
3. 施術ブロック
   ├ 通常必要とされる治療内容（要件③）
   ├ 標準的な費用（要件③）※「〇〇円から」の下限のみは不可
   ├ 治療期間および回数（要件③）※最も落としやすい
   └ 主なリスク・副作用（要件④）
4. 症例写真（載せる場合）
   └ 1件ごとに 治療内容・費用・期間回数・リスク副作用を併記
      ※まとめ書きは不可。リンク先へ逃がすのも不可
5. Q&A
6. 予約導線
7. フッター
```

**42ドメインを実測して、4要件を完全に満たすLPは1件も確認できなかった。**
最頻の欠落は「治療期間および回数」。費用だけ書いて期間回数を落とす型が支配的。

適合度が高かった実例：
- 品川美容外科：各施術ブロック内に「副作用・リスク」見出しと「ハレ/痛み：2日から1週間位。
  内出血：1から2週間位。」を**料金の直近**に配置。
- 銀座総合美容クリニック：症例写真の直下に費用とリスクを1つの注記にまとめて併記。
- Oh my teeth：症例ごとに「20代 | 女性 | 喫煙者 期間：1ヶ月」と自由診療・個人差の注記。

**体験談・お客様の声は置けない**（限定解除でも解除されない省令の禁止事項）。実測でも
歯科自費サイトは揃って「お客様の声」を置かず症例写真＋注記で代替していた。医療法適用外の
整体・接骨院だけが体験談と不安訴求型FVを維持している。

## 教育・人材・スクール

```
1. FV（不安・悩み訴求または実績数値）
2. 無料オファーの提示（無料＋所要時間＋断りやすさ）
3. 課題・共感
4. サービス内容
5. 実績数値（※注釈必須）
6. 受講生・利用者の声
7. 中間CTA（複数回）
8. 講師・アドバイザー紹介（顔出し）
9. 料金・給付金・返金保証
10. 流れ
11. Q&A
12. 最終CTA
13. フッター
```

**「無料」は必ず「所要時間」とセットで書く。** 実測でほぼ例外なく複合形だった：
「簡単30秒で無料登録」（ギークリー）、「3分で登録完了！転職サポートお申込み」
（パソナキャリア）、「30秒でカンタン予約」（プログリット）、「かんたん１分 無料体験レッスンの
ご予約」（Gaba）、「【最短1分】無料登録スタート」（ジェイック）。

**「断ってよい」と明示するコピーが高関与オファーの緩衝材として機能している**：
「体験授業で入塾を決めなくていい」（東京個別指導学院）、「一人でできそうなら入塾しなくて
かまいません」（武田塾）、「ビデオオフでもOK！」（ポテパンキャンプ）、
「＼他のスクールとの比較検討相談も可能です。／」（DIVE INTO CODE）。

法規制の分岐：語学教室・家庭教師・学習塾・パソコン教室は**期間2か月超かつ5万円超**で
特定継続的役務提供に該当（エステ・美容医療は1か月超）。プログラミングスクールは
原則非該当。詳細は [`legal.md`](legal.md)。

## 高額・長期検討型（住宅／不動産／保険／金融／リフォーム）

**即決CTAを置かない。** 実物確認した注文住宅16サイトのうち、トップ階層に「今すぐ契約」に
相当するCTAを置いていたサイトは**ゼロ件**。

```
1. FV（ビジュアルまたは実績数値）
2. 中間CVの3本立て（カタログ請求／来場予約／オンライン相談）
3. 課題・共感
4. 施工実績数・施工事例写真
5. 信頼構築（保証年数、有資格者、地域密着年数、受賞歴）
6. 「無理な営業はしません」ブロック ← 一括見積もり型では事実上の必須
7. 流れ
8. 費用の目安
9. Q&A
10. フォーム（ステップ分割）
11. フッター（金融ならリスク全文、不動産なら情報公開日と次回更新予定日）
```

### 一括見積もり型はステップフォーム

3から4ステップに分割し、番号付きインジケーターを置く。実物で全ステップを確定できた例：
- ソーラーパートナーズ：3ステップ（きっかけ → 設置場所 → かんたん見積り）
- エコ発：4ステップ（建物情報 → 屋根の形状 → お客様 → 完了）
- 外壁塗装パートナーズ：3ステップ（都道府県 → 塗装場所 → 工事内容）

### 「営業されるのが怖い」の打ち消しは日本特有

実測した全社が何らかの形で置いていた。しかも**運営が営業を止める仕組みまで明示する**のが
日本的：
- ヌリカエ「いきなり複数の会社から連絡が入ることはありません。」＋お断り代行
- ソーラーパートナーズ「強引な営業を禁止しています。」＋イエローカード制度
- エコ発「業者からの大量の営業電話も一切ありません」
- 御浜建設「無理な営業は一切いたしません。」

### フォーム項目数の実態

同じ「資料請求」でも**14項目から49項目まで3.5倍の開き**がある。

| サイト | 項目数 | 備考 |
|---|---|---|
| 住友不動産 | 全14（必須9） | 3ステップ分割 |
| ユニバーサルホーム | 全18（必須11） | |
| 桧家住宅 | **全49（必須12）** | FVに「1分で完了」と表示。任意に年収・総予算・住宅ローン・融資事前審査希望まで含む |

**CTAの文言とフォームの実態を乖離させない。** 「1分で完了」と書いて49項目は、
期待と現実の落差そのものが離脱要因になる。
