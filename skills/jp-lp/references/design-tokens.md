# 和文タイポグラフィとUIの実務値

Playwright実描画78件（CV目的LP 42件、デザイン評価軸サイト36件）の computed style 実測。
加えて LP archive 46,006件のスタイルタグ全件タリー。

## なぜ欧文の値をそのまま使えないか

和文は正方形の仮想ボディに文字を収めて**ベタ組み**するのが原則で、行長は文字サイズの整数倍で
設計される（W3C 日本語組版処理の要件 https://www.w3.org/TR/jlreq/ ）。欧文のように
ディセンダ・アセンダが行間に余白を作る構造がなく、漢字は字画が多く字面が仮想ボディいっぱいまで
詰まる。**同じ line-height でも行と行が物理的に近接する。** したがって行送りを外から足す。

**注記：JLReq本文には行送りの推奨倍率の明示がない**（確認済み）。下記の倍率の根拠は
実測と二次情報のみ。

## 実装値の早見表

| 用途 | font-size | line-height | letter-spacing |
|---|---|---|---|
| モバイル本文 | **16px**（実測中央値は13.9pxだが下記の理由で16pxを推す） | 1.7から1.8 | 0.02emから0.05em |
| 見出し H2 相当 | 24pxから32px（実測中央値24px） | 1.4から1.5 | 0.02emから0.06em |
| 大見出し・FVキャッチ | 28pxから40px（実測H1中央値28.6px、最大40px） | 1.2から1.4 | 0から0.04em（詰めるなら -0.02em まで） |
| キャプション・注記 | 12pxを下限。**打消し表示には使わない** | 1.6から1.7 | 0.02em |
| CTAラベル | 16pxから18px（実測中央値15px） | 1.4 | 0.04emから0.08em |

### 本文 line-height は 1.70 が基準

CV目的LP 40件の文字数加重 line-height は**中央値1.70**。1.6以上が29/40（73%）、
1.5未満はわずか3/40（8%）。デザイン評価軸群36件では中央値1.80、1.75以上が23/36（64%）。

**下限1.6、上限1.8。** 二次情報も一致（和文本文1.8から2.0、欧文本文1.5から1.8）。

### 見出しは本文より必ず詰める

CV目的LPの**74%（26/35サイト）**が見出しの line-height を本文より小さくしていた。
デザイン評価軸群では**91%（30/33）**。全見出し（H1からH3、日本語3字以上、n=443）の
line-height 中央値は**1.5**、最頻値も1.5（149件）。

大きな文字で本文と同じ行間だと、行間が空きすぎて逆に読みにくくなる。

### letter-spacing はほぼ触られていない

- CV目的LPの見出し（n=443）で `letter-spacing: normal`（未指定）が**61%**
- デザイン評価軸群の見出し（n=318）では `normal` が**43%**まで下がる
- 本文では CV目的LP 42件中29件が `normal`

**トラッキングを触るかどうかが、CV目的LPとデザイン評価軸サイトの分岐点のひとつ。**
CV目的なら触らなくてよい。

### 推奨するCSSの骨格

```css
:root {
  --lh-body: 1.75;
  --lh-head: 1.45;
}
body {
  font-family: "Noto Sans JP", "Hiragino Sans", "Yu Gothic", sans-serif;
  font-size: 16px;
  line-height: var(--lh-body);
  letter-spacing: 0.03em;
  font-feature-settings: "palt" 1;   /* 和文の詰め組み */
}
h1, h2, h3 {
  line-height: var(--lh-head);
  letter-spacing: 0.02em;
  line-break: strict;                /* 禁則処理 */
}
p, li, td { word-break: normal; overflow-wrap: anywhere; }
```

`overflow-wrap: anywhere` は長いURLだけを折るため。`word-break: break-all` を和文に当てると
禁則が壊れる。

## CTAの寸法

モバイル実測中央値（n=31）：

| 項目 | 実測値 |
|---|---|
| 幅 | **328px**（390px幅の84%） |
| 高さ | **62px** |
| ラベル font-size | 15px |
| 44px以上の高さを満たすもの | 91% |
| 角丸 | **0px が最頻（13/31）**、次いで完全な丸（50pxから100px）が5件 |

角丸0pxが最頻というのは欧米のUI慣行と逆なので注意。日本のCV目的LPでは
「四角いベタ塗りボタン」が主流。

## CTAの色

有効42件中31件で主CTAの背景色を取得：白8、オレンジ6、黄4、赤4、青2、グレー2、黒2、緑2、青緑1。

**「日本のCTAはオレンジか赤」という通説は、オレンジ＋赤＋黄で14/31（45%）という意味では
支持されるが、過半ではない。**

実測から見えた原則は色そのものではなく、
**「ページの主色の補色側で、その面の中で唯一その色である」こと**。
業種別の定番配色より、面内での一意性が優先されている。

**コントラスト事故が実在する。** オレンジに白文字（`#ff740f` ＋ 白 ＝ 2.71:1）は
WCAG AA（4.5:1）を満たさない。CTAは最も押される要素なので、ここのコントラスト不足は致命的。

## アクセシビリティ：日本語の「大きな文字」は22pt

WCAG 2.1 達成基準1.4.3の解説は、日本語の全角文字について拡大教科書普及推進会議 第一次報告に
基づき「**22ポイント又は18ポイントの太字**」を同等サイズとみなすのが妥当とし、
「1pt = 1.333px であり 22pt と 18pt は約 **29px と 24px** に相当する」と明記している。
https://waic.jp/docs/WCAG21/Understanding/contrast-minimum.html

**実測の見出し font-size 中央値は19.1px。** つまり日本語LPの見出しの大半は
3:1 の緩和（大きな文字）の対象外で、**4.5:1 が必要**。

英語圏の「18pt以上なら3:1でよい」をそのまま適用すると、日本語では基準を外す。

## 打消し表示の文字サイズ（最大の実務ギャップ）

消費者庁は求められる表示方法として「同一画面にある他の表示と比べても、**打消し表示がより
注意を引き付ける文字の大きさにすること**」と明記している。

にもかかわらず実測では **14px未満のテキストを持つLPが37/42（88%）**、最大で1ページ478要素。

**注記を小さくするのは、デザインの問題ではなく法的リスク。** 詳細は
[`legal.md`](legal.md) のA節。

## 使われていない装飾（通説と実態が逆）

CV目的LP 42件の実測：

| 装飾 | 出現 |
|---|---|
| 袋文字（`-webkit-text-stroke`） | **0/42（0%）** |
| 和文 italic | 1/42（2%）※デザイン評価軸群では 0/36 |
| 蛍光マーカー（透明グラデーション下線） | 4/42（10%） |
| `text-shadow` | 5/42（12%） |
| **赤系＋太字のテキスト** | **16/42（38%）** |

**「日本のLPは装飾過多」という前提で袋文字・斜体・影を標準採用するのは実態と逆。**
生き残っている強調手段は**赤字＋太字だけ**。分岐点は手法ではなく密度。

なお和文 italic は避ける。多くの和文フォントにイタリック字形がなく、ブラウザが機械的に
斜変形するため字形が壊れる。CSS宣言としては35%のサイトに存在するが（Bootstrap等の残骸）、
和文には適用されていない。

## CV目的LPで使われない技術

| 技術 | CV目的LP | デザイン評価軸 |
|---|---|---|
| Lenis / LocomotiveScroll（慣性スクロール） | **0/45（0%）** | 18/40（45%） |
| GSAP | 6/45（13%） | 15/40（38%） |
| three.js / WebGL | 2/45（4%） | 5/40（12%） |
| `clamp()` 流体タイポ | 9/45（20%） | 22/40（55%） |
| `mix-blend-mode` | 7% | 45% |
| Swiper | **36%** | 25%（唯一CV群が上回る） |

**「かっこいいが売れない」領域は実測上ほぼきれいに二分されている。** 慣性スクロールを
CV目的LPに入れるのは、実測上ゼロの選択。カルーセル（Swiper）だけがCV群で多い。

## 素材写真＋吹き出しは規約違反になりうる

**PIXTAの規約は「人物素材に吹き出しを付けて商品利用の印象を与える使用」を明確に禁止している。**

日本のLPの定番構成である「素材写真＋吹き出しのお客様の声」は、この規約に抵触する。
医療LPではそもそも体験談自体が禁止（[`legal.md`](legal.md) D節）。

使うなら、実際の顧客の許諾を取った写真か、モデルリリース済みでこの用途が許諾されている素材を
使う。素材サイトの規約は必ずその都度確認すること（規約は改定される）。

## 読まれ方の前提

消費者庁の調査（回答1,000名）：**拾い読み66.5%、非スクロール40.4%、注釈見落とし68から94%。**

にもかかわらず実測では14px未満テキストを持つLPが88%、**ダークモード対応9%**、
**テキストH1不在76%**。

設計の含意：拾い読みされる前提で、見出しだけで筋が通るように書く。注釈は見落とされる前提で、
重要な条件は本文と同じ大きさで本文中に置く。
