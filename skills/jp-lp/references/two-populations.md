# 2つの母集団：日本のLPは統計的に別物が2種類ある

調査日 2026-08-05。ギャラリー掲載型 49件、広告配信型 55件を実物で計測。

## なぜこの区別が要るか

「日本のLPといえば縦長・赤字・吹き出し・マンガ」という通説を検証したところ、
**通説が成立する母集団と、成立しない母集団に割れた**。

- ギャラリー掲載型（LP archive、Web Design Clip、MUUUUU.ORG、lp-web.com 等の掲載LP）：
  通説は**棄却**された。
- 広告配信型（Meta広告ライブラリの遷移先。ギャラリーには載らない）：通説は**支持**された。

つまり通説そのものが誤りだったのではなく、**通説が指していた層がデザインギャラリーに
載らない層だった**。ギャラリーは「作品として見せられるLP」を選ぶので、その選抜フィルタが
赤字・吹き出し・比較表を落とす。

## マンガLPは「日本の型」ではない

両母集団とも実質ゼロ。広告配信型でも 2/54（3.7%）で、その2件はどちらも投資・不動産投資
（キャピタルハック、マネきゃん）。健康食品16件・化粧品14件・医療脱毛8件では**0件**。

LP archive 46,006件のスタイルタグ実測でも「マンガ・イラスト」は 1,747件（3.8%）。
最大タグは「シンプル」13,303件（28.9%）、次いで「かわいい」8,821件（19.2%）、
「信頼・安心」8,435件（18.3%）。「派手」は 2,090件（4.5%）。

**マンガLPは「投資・不動産・高単価リード獲得という限られた文脈の型」として扱う。**
制作コストが高い割に、標本上は使われていない領域が広い。

**化粧品は二層に割れる。** 大手ブランドの公式LP（アスタリフト、アテニア、ディセンシア、
ライスパワー、オルビス本体、LUCENA）は赤字も吹き出しも比較表もゼロ。同じ化粧品でも
記事LP・単品通販カート型（CAC、KATAN、インナーシグナル、アースケア、エポ）は装飾が濃い。

**不動産投資が最も薄い。** 金融商品取引法・宅建業法の広告規制が効いていて煽り文字を
使いにくいためと考えられる（推定）。代わりに比較表と実績数値で構成する。

**薬機法上「効果効能を断定できない」商材ほど装飾が濃くなる**構図が見える（推定）。
断定できない分を装飾の圧で補っている。

## 記事LP（アドバトリアル）という第3の型

広告配信型55件中17件が `/ab/` パスを持つ記事LP。Squad beyond 等のツールで作られる。
**装飾の濃さが別格で、他のどの型とも別に扱う必要がある。**

| 指標 | 記事LP（n=17） | 記事LP以外 |
|---|---|---|
| 赤字・黄色マーカー | **17/17（100%）** | 大きく下回る |
| 吹き出し | 12/16（75%） | 同上 |
| 縦の長さ中央値 | **29,078px** | 14,821px（ちょうど2倍） |
| 固定追従CTA | **0/17（0%）** | あり |
| 明示CTA 0個 | 5/17 | 稀 |

ドメインが `sb-〇〇.discover-news.tokyo`、`sb-〇〇.service-info.jp`、`sb-〇〇.ourpage.jp`、
`sb.taisho-direct.jp` のように**広告主ドメインとは別のニュースメディア風サブドメイン**に
なっているのが特徴。冒頭または末尾に小さく「PR：株式会社〇〇」と表示される
（ステマ規制対応と思われる）。

### 記事LPの構造

```
体験談風の書き出し（一人称・悩みの提示）
 → 原因の解説（図解・赤字強調・黄色マーカー）
 → 商品の登場（「あの大正製薬が」「あのロキソニンSの会社が」＝親会社の権威借用）
 → 臨床試験グラフ・機能性表示食品の届出訴求
 → お客様の声
 → 価格開示（通常価格に取り消し線＋初回価格）
 → 4問前後のアンケート（クリックのみ）
 → 「ご回答ありがとうございました！」→ 特別価格ページへ送客
```

末尾アンケートは、**同意の階段（コミットメントと一貫性）を作りつつ、フォーム到達前に
離脱者を切って広告計測上の到達品質を上げる**ためと考えられる（推定）。
55件中、ラジオ・チェックボックスを3個以上持つLPは20件あった。

固定追従CTAを置かないのは、記事の没入を切る要素として意図的に外していると考えられる。
**「追従ボタンを置くのが日本の作法」は記事LPには当てはまらない。**

## もう1つの極：1画面完結型

3,000px未満の「1画面完結アンケート型／フォーム一体型」が広告配信型55件中7件（12.7%）。
ギャラリー型では「短い」は1件（2.1%）しかない。

実例：レジーナクリニック `/lp/25_ailpo_fb/`（844px）、N organic `ab.sirok.jp/ab/basic_trial_107`
（1,095px）、WORKCANVAS `/lp5/enquete`（905px）、BI-SU `cart.bi-su.jp/ad.php`（1,211px）、
ATOM `atom-aga.com/clinic/ryuzi01`（844px）。

開いた瞬間に「Q1 今までに脱毛をした経験はありますか？」のような設問が出る。転職系では
「LINEで担当者が紹介します」型に変わる。

**日本の広告配信LPは「極端に長い」と「極端に短い」の二極化が起きている。**
「日本のLP＝縦長」を単純に適用すると外す領域がある。

## 広告配信型に特有の実装

- **媒体別にLPを作り分けている。** URLに `_facebook` `_fb` `meta` `asc`（Advantage+ Shopping
  Campaign）といった配信面識別子が入っている（`ej_1st_kiji_facebook`、
  `aojiruplus_article001_fb`、`hizatect-meta-notadnw`、`orbd-f2-03q-fk005`）。
- **フォーム一体型**：55件中、可視入力欄10個以上が13件。カートページへ遷移させない。
  ecforce（SUPER STUDIO）系と思われる `https://ドメイン/lp?u=キャンペーンID` 形式が多い。
  Amazon Pay ログインボタンをフォーム冒頭に置いて入力自体を飛ばす設計も複数。
- **通常価格に取り消し線＋初回価格の巨大表示**：「4,320円→980円（77%OFF）」形式が標準。
- **在庫・期間の限定**：「毎月数量限定」「完売次第終了」。**日付を当日にして毎日書き換えて
  いる実装**が見られた（2026-08-05に「8月5日（水）限定」表示）。これは景表法上の危険が高い
  （常時実施の「期間限定」表示で措置命令が出た実例がある。`legal.md` 参照）。
- **離脱ブロックは少数**：`beforeunload` 等を検出できたのは55件中2件のみ。
  「日本のLPは離脱ブロックだらけ」はこの標本では裏付けられなかった。

## やってはいけないこと

1. **ギャラリー掲載型の装飾レベルを広告配信型に持ち込む（逆も同じ）。** 混ざったものができる。
2. **マンガLPを「日本の定番」として提案する。** 標本上は限られた文脈でしか使われていない。
3. **比較表を根拠なしに作る。** 比較広告は景表法の領域で、実証された数値・出典・調査時点の
   併記が要る。今回見た比較表の多くは注釈付きだったが、読めないほど小さいものもあった。
4. **装飾の出現率を効果の証拠として引用する。** CVRは測っていない。
